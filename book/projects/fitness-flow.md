## Technical Details

1. **Full-Stack:** Built a full-stack application with Next.js frontend and Firebase backend, implementing real-time data synchronization across devices.

2. **Analytics Dashboards:** Designed interactive analytics dashboards displaying workout progress, calorie tracking, and streak management with data visualizations.

3. **Authentication:** Implemented user authentication, data persistence, and cross-device sync using Firebase Authentication and Firestore.

4. **Responsive UI:** Created responsive UI with Tailwind CSS ensuring consistent experience across mobile and desktop platforms.
