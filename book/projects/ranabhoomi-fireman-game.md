## Overview

Designed and implemented a multiplayer fireman-themed game using C++ and SFML. Features custom sprite management, real-time graphics rendering, and networked multiplayer logic.

## Technical Details

1. **Game Mechanics:** Designed and implemented core game mechanics including firefighting simulation, level progression, and score management.

2. **Sprite System:** Built custom sprite management system with animation state machines for character movement, fire spreading, and water effects.

3. **Event System:** Implemented event-driven architecture with collision detection, particle effects for fire and water, and interactive environment elements.

4. **Multiplayer:** Added multiplayer support with networked game state synchronization for cooperative gameplay.
